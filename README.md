# 🍪 Cookies Juninos — Landing Page

Landing page do evento **Cookies Juninos** da [Flávia Maskavo](https://cookies-juninos.comunidademaskavo.com.br/), onde ela ensina receitas temáticas de São João com foco em vendas.

**Acesse:** [cookies-juninos.comunidademaskavo.com.br](https://cookies-juninos.comunidademaskavo.com.br/)

---

## Sobre o evento

Em 2 dias de aulas ao vivo, as alunas aprendem cookies temáticos — como Cookie Maçã do Amor e Cookie Pamonha — com técnicas de produção, finalização e estratégias para vender mais no São João.

## Stack

- React 19 + TypeScript
- TanStack Start + TanStack Router
- Tailwind CSS v4
- shadcn/ui
- Deploy na Cloudflare

## Rodando localmente

```bash
bun install
bun dev
```
